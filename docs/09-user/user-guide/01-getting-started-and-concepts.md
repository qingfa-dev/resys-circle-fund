# User Guide — Getting Started & Concepts

**Index:** `docs/09-user/user-guide.md`

## Create an Account

1. Open CircleFund → tap **Register**.
2. Enter username/email, a strong password (≥8 chars, mixed case + digit + symbol), confirm.
3. Submit → check email → click the verification link.
4. Log in with the new credentials.

> Registration/verification require connectivity. On a previously-used device you can unlock **offline, read-only** (FR-I1-040).

## Log In

1. Enter email/username + password → **Login**.
2. On a known device offline, the app unlocks from a cached credential (read-only).

## Core Concepts

| Term | Meaning |
| --- | --- |
| Savings Circle | one ROSCA group (members, schedule, rules) |
| Round | one cycle; every member contributes, one receives the pool |
| Share | a contribution unit; a member may hold several |
| Payout Draw | a member receiving the pooled funds for a round |
| Association Type | No-Interest Rotation · Fixed Interest · Bidding |
