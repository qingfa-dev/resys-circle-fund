# User Guide — Offline & Troubleshooting

**Index:** `docs/09-user/user-guide.md`

## Offline & Synchronization
- Work offline; operations sync automatically (FR-I1-042).
- Watch the sync indicator: pending / syncing / synced / conflict / offline.
- On conflict, CircleFund shows both versions; nothing is discarded silently (FR-I1-044).

## Troubleshooting

| Issue | Solution |
| --- | --- |
| Can't log in | Check credentials; Forgot Password |
| Record shows "pending" | Offline or sync in progress |
| Balance looks wrong | Pending records aren't counted; sync then re-check |
| Conflict shown | Compare both versions and choose |

See `docs/09-user/faq/` for more.
