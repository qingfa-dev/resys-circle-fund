# User Guide — Core Operations

**Index:** `docs/09-user/user-guide.md`

## Dashboard
Shows active circles, upcoming rounds, unpaid contributions, outstanding debt, and financial summary.

## Create a Circle
1. **Circles → New Circle**.
2. Enter Name, Association Type, start date, contribution amount, schedule, number of rounds.
3. **Create** → add members → assign shares.

## Record a Contribution (online or offline)
1. Open the circle → **Record Contribution**.
2. Select member, round, share, amount, payment date, method (cash/bank/e-wallet), optional reference/note.
3. Review the preview + balance impact → **Confirm**.

Offline: the contribution is saved as **pending** and syncs automatically; pending records don't count toward balances until synced.

## Balances
Always derived from the ledger. View member balance, round collection status, and overall circle balance.

## Payout Draw & Bidding
- **Payout Draw:** record who received the pooled funds; net amount = contributions − discount/interest.
- **Bidding:** members bid; the configured rule (e.g., highest) selects the winner.
