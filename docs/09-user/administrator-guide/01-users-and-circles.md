# Administrator Guide — Users & Circles

**Index:** `docs/09-user/administrator-guide.md`

## User Management
- View / activate / deactivate accounts.
- Reset passwords; edit profiles; assign roles.
- Review per-user audit trail.
- Roles: System Administrator, Group Owner, Circle Organizer, Treasurer, Secretary, Moderator, Circle Member, Viewer.

## Circle Administration

| Area | Config |
| --- | --- |
| Association Types | enable + default rules (No-Interest Rotation / Fixed Interest / Bidding) |
| Authentication | password policy, session timeout, lockout, token expiry |
| Notifications | channels, reminder schedule, templates |
| Financial defaults | currency, rounding, max transaction, reconciliation |
| System | maintenance mode, public registration, audit retention |
