# FAQ — Getting Started & Account

**Index:** `docs/09-user/faq.md`

**What is CircleFund?** An open-source web app for managing rotating savings and credit associations (ROSCAs, Vietnamese Hụi/Họ).

**Who is it for?** Circle Organizers, Circle Members, Treasurers, Secretaries.

**Is it free?** Yes — MIT License.

**Does CircleFund work offline?** Yes — day-1 feature. Record and manage offline; it syncs automatically.

**How do I log in offline?** A previously-authenticated device unlocks via a cached credential for a read-only session (FR-I1-040).

**I forgot my password.** Use Forgot Password.
