# FAQ — Integrations & Support

**Index:** `docs/09-user/faq.md`

**Can I attach receipts?** Yes — file storage with validation and access control.

**Can I log in with Google/Facebook?** Yes once external auth is enabled; you can revoke links anytime.

**Can I type a payment in plain Vietnamese?** Yes — AI-assisted entry interprets a sentence like *"Đã thu 500 nghìn của Nguyễn A cho kỳ 5"* into a proposed transaction you confirm. AI never commits directly.

**Found a bug?** Search GitHub issues, then file one with repro, expected vs actual, browser/device, screenshots.

**Feature request?** Check the roadmap, then open an issue describing the business need.
