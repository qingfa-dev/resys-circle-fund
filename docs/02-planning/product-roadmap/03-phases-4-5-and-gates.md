# Product Roadmap — Phases 4–5 & Gates

**Index:** `docs/02-planning/product-roadmap.md`

## Phase 4 — Group Collaboration
Groups, invitations, roles/permissions, announcements, voting, rules, fines/appeals, chat, meetings, tasks.

## Phase 5 — Advanced Platform
Accounts/transfers, budgets, invoices, documents, calendar, import/export, sharing, community.

## Milestone-Gate Criteria
- P1: offline capture + exactly-once sync verified; duplicates prevented; balances verified.
- P2: operations traceable; bidding/payout E2E; conflict escalation verified.
- P3: each integration has a documented failure mode + degradation test.
- P4: role-based permissions enforced; voting workflows verified.
- P5: import/export data integrity + offline sync verified for financial data.
