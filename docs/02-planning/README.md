# 02-planning — README

## Purpose

Project-level planning: the five-phase roadmap, the per-iteration/per-sprint plans, and the release strategy. Answers "what are we building and in what order."

## Key Terms

- **Roadmap** — the 5-phase product plan (product-roadmap).
- **Iteration Plan** — sprints, epics, objectives, dependencies, exit criteria.
- **Release Plan** — iteration → release mapping.

## Usage

- **Understand sequencing:** `product-roadmap/` phases + gates.
- **Plan a sprint:** `iteration-plan/<NN>-iteration-*.md` (sprint table + objectives).
- **Map releases:** `release-plan/`.
