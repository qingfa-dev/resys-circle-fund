# 00-governance — README

## Purpose

This folder holds the **project's governing documents**: the charter (what and why), the development plan (how), the documentation plan (how docs are produced), the glossary (the shared vocabulary), and references (standards). It is the orientation entry point — read this before anything else.

## Key Terms

| Term | Meaning |
| --- | --- |
| Project Charter | vision, objectives, scope, stakeholders, constraints |
| Development Plan | SDLC, Definition of Ready/Done, cross-cutting epics, gates |
| Documentation Plan | doc standards, ownership, maintenance |
| Glossary | English↔Vietnamese domain terminology + actor/abbreviation tables |
| References | standards (IEEE) + internal cross-links |

## Contents

## Usage

- **New contributor / agent:** read in order — charter → glossary → development plan.
- **Questioning a term:** `glossary.md`.
- **Looking for a standard citation:** `references.md`.
