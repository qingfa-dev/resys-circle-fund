# ADR Template — Future Architecture Decisions

## How to Use

When an architecture decision is made, create a new file following this template:

- Number sequentially: `ADR-005-...`, `ADR-006-...`, etc.
- Use kebab-case in filename
- Keep filename descriptive of the decision topic

## Template

```text
# ADR-XXX: [Short descriptive title]

## Status

[Proposed | Accepted | Deferred | Superseded]

## Context

[What is the situation/problem being addressed?]

## Decision

[What was decided? Include alternatives considered.]

## Consequences

### Positive

- [What benefits result from this decision?]

### Negative

- [What drawbacks or costs result?]

### Risks

- [What risks does this introduce?]
- [How will they be mitigated?]

## Mitigations

- [Specific actions to address risks and negative consequences]
```
