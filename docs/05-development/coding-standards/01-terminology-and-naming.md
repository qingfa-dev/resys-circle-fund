# Coding Standards — Terminology & Naming

**Index:** `docs/05-development/coding-standards.md`

## Terminology
Code uses CircleFund English terms (glossary): `Circle`, `CircleOrganizer`, `CircleMember`, `Round` (not "Period"), `Share`, `Contribution`, `PayoutDraw`/`Payout`, `Bid`, `Bidding`, `NoInterestRotation`, `FixedInterest`, `Reconciliation`, `OutstandingDebt`, `Ledger`, `AssociationType`. Vietnamese only in glossary/SRS.

## Naming

| Element | Convention |
| --- | --- |
| C# Class/Method | PascalCase |
| C# Variable | camelCase |
| TS Interface/Type | PascalCase |
| TS Variable/Function | camelCase |
| Vue Component | PascalCase file / kebab-case usage |
| Pinia Store | camelCase |
| API Route | kebab-case |
| DB Table/Column | snake_case |
