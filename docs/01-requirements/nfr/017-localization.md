# NFR-017 — Localization

**Category:** Localization
**Applies:** I1–I5

**Statement:** The system shall avoid hard-coding user-facing text throughout business logic. Values such as "Đã đóng" (Paid), "Chưa đóng" (Unpaid), "Quá hạn" (Overdue) should be represented using application-level localization resources rather than scattered string literals.
