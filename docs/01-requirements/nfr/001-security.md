# NFR-001 — Security

**Category:** Security
**Applies:** I1–I5 (✓, ✓✓ from I2)

**Statement:** The system shall protect user accounts and application resources against unauthorized access.

**Sub-requirements:**
- NFR-001.1 Secure authentication
- NFR-001.2 Password hashing
- NFR-001.3 Session/token expiration
- NFR-001.4 Authorization checks
- NFR-001.5 Resource-level authorization
- NFR-001.6 Secret protection
- NFR-001.7 Input validation
- NFR-001.8 Protection against injection
