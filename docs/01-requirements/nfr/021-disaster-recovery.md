# NFR-021 — Disaster Recovery

**Category:** Disaster Recovery
**Applies:** Basic I1; I2 ✓; I3 ✓✓; I4 ✓; I5 ✓✓

**Statement:** The system shall define RPO (Recovery Point Objective) and RTO (Recovery Time Objective). Example targets for a small deployment: RPO ≤ 24 hours, RTO ≤ 4 hours. These are proposed baselines to be adjusted according to actual business requirements.
