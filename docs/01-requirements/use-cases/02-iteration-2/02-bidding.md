# Bidding — Use Cases

**Iteration:** 2 — Financial Operations (Offline-Capable)
**SRS:** `docs/01-requirements/srs.md` §3.2.2

## UC-I2-006 — Open Bidding
Open bidding window for a round.

## UC-I2-007 — Submit Bid
Eligible member submits bid → validate → record.

## UC-I2-008 — Validate Bid
Enforce bid rules and minimum amounts.

## UC-I2-009 — Close Bidding
Close bidding window.

## UC-I2-010 — Determine Winner
Apply configured rule → select winner.

## UC-I2-011 — Record Winning Result
Link winner to the round.

## Associated User Stories
- US-I2-003 — *As a Circle Member, I want to submit a bid when bidding is open.*
- US-I2-004 — *As a Circle Organizer, I want the winning bid to be determined according to the configured rules.*
