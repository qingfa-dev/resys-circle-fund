# Dashboard & Notifications — Use Cases

**Iteration:** 1 — Offline-First Core ROSCA Management
**SRS:** `docs/01-requirements/srs.md` §3.1.7

## UC-I1-038 — View Dashboard
**Actor:** Circle Organizer / Circle Member. Aggregate circles, rounds, unpaid, debt, activity, summary.

## UC-I1-039 — Generate Reminder
**Actor:** Scheduler. Identify unpaid → generate reminder.

## UC-I1-040 — View Reminder Status
**Actor:** Circle Organizer. Retrieve generation/delivery status.

## Associated User Stories
- US-I1-021 — *As a user, I want a dashboard summarizing my circles, upcoming rounds, and outstanding contributions so that I can quickly understand my current status.*
- US-I1-022 — *As a Circle Member, I want to receive a reminder before a contribution is due so that I don't miss a payment.*
