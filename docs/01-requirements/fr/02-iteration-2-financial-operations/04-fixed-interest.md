# Fixed Interest — Functional Requirements

**Iteration:** 2 — Financial Operations (Offline-Capable)
**SRS:** `docs/01-requirements/srs.md` §3.2.4

## FR-I2-017

**Statement:** The system shall support fixed-interest calculations.

## FR-I2-018

**Statement:** The system shall store the configured rate/rule.

## FR-I2-019

**Statement:** The system shall calculate amounts using a consistent rounding policy (BR-FIN-007).

## FR-I2-020

**Statement:** Historical calculations shall not change merely because the configuration is later modified (BR-FIN-006).

**Related:** UC-I2-017..019, US-I2-007, BR-FIN-006/007
