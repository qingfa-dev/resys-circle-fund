# Audit — Functional Requirements

**Iteration:** 2 — Financial Operations (Offline-Capable)
**SRS:** `docs/01-requirements/srs.md` §3.2.9

## FR-I2-037

**Statement:** The system shall record sensitive financial actions (BR-AUD-001).

## FR-I2-038

**Statement:** An audit record shall include: Actor, Action, Timestamp, Resource, Before, After, Correlation ID, Reason (BR-AUD-002).

## FR-I2-039

**Statement:** Authorized users shall be able to search audit records.

**Related:** UC-I2-036..038, US-I2-015, BR-AUD-001/002, NFR-011
