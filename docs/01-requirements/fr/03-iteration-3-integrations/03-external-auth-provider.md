# External Authentication Provider — Functional Requirements

**Iteration:** 3 — Integrations (External Services)
**SRS:** `docs/01-requirements/srs.md` §3.3.3

## FR-I3-011

**Statement:** The system shall support login via a connected external identity provider where enabled.

## FR-I3-012

**Statement:** The system shall link an external identity to an existing account, or create a new account, per configured policy.

## FR-I3-013

**Statement:** A user shall be able to view and revoke connected external identity providers from their profile.

**Related:** UC-I3-011..013, US-I3-005/006, NFR-001
