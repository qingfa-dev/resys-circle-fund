# Analytics Integration — Functional Requirements

**Iteration:** 3 — Integrations (External Services)
**SRS:** `docs/01-requirements/srs.md` §3.3.5

## FR-I3-019

**Statement:** The system shall provide collection analytics via the connected Analytics/Reporting Engine.

## FR-I3-020

**Statement:** The system shall provide ROSCA performance summaries.

## FR-I3-021

**Statement:** Analytics shall provide date/group/circle filtering where applicable.

## FR-I3-022

**Statement:** Analytics shall not alter authoritative financial records.

**Related:** UC-I3-019..022, US-I3-009, NFR-003 (read-only aggregate)
