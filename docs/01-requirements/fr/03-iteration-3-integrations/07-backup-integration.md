# Backup Integration — Functional Requirements

**Iteration:** 3 — Integrations (External Services)
**SRS:** `docs/01-requirements/srs.md` §3.3.7

## FR-I3-027

**Statement:** The system shall support scheduled backups to the connected Backup Storage.

## FR-I3-028

**Statement:** Authorized administrators shall be able to create backups manually.

## FR-I3-029

**Statement:** The system shall retain backup metadata.

## FR-I3-030

**Statement:** Authorized administrators shall be able to restore from a valid backup.

## FR-I3-031

**Statement:** Restore operations shall be audited.

**Related:** UC-I3-027..031, US-I3-012/013, BR-INT-003, NFR-020/021
