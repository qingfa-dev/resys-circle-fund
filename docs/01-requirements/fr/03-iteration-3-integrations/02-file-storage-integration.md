# File Storage Integration — Functional Requirements

**Iteration:** 3 — Integrations (External Services)
**SRS:** `docs/01-requirements/srs.md` §3.3.2

## FR-I3-006

**Statement:** The system shall store uploaded files through the connected File Storage Service.

## FR-I3-007

**Statement:** The system shall validate file type and size before upload.

## FR-I3-008

**Statement:** The system shall scan uploaded files for malicious content where supported.

## FR-I3-009

**Statement:** File access shall be authorized per the resource's ownership/permission rules.

## FR-I3-010

**Statement:** The system shall support retrieval of previously stored files by reference.

**Related:** UC-I3-006..010, US-I3-003/004, NFR-031 (File Security)
