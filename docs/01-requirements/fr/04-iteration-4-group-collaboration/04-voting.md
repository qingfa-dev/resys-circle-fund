# Voting — Functional Requirements

**Iteration:** 4 — Group Collaboration & Governance
**SRS:** `docs/01-requirements/srs.md` §3.4.4

## FR-I4-013

**Statement:** Authorized users shall be able to create votes.

## FR-I4-014

**Statement:** A vote shall define: Question, Options, Eligible voters, Start time, End time, Quorum, Voting rules.

## FR-I4-015

**Statement:** Eligible users shall be able to vote.

## FR-I4-016

**Statement:** A user shall normally vote only once per vote unless configured rules allow changes.

## FR-I4-017

**Statement:** The system shall calculate results.

## FR-I4-018

**Statement:** The system shall calculate quorum where configured.
