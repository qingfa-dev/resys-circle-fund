# Tasks — Functional Requirements

**Iteration:** 4 — Group Collaboration & Governance
**SRS:** `docs/01-requirements/srs.md` §3.4.9

## FR-I4-035

**Statement:** Authorized users shall be able to create group tasks.

## FR-I4-036

**Statement:** A task shall support: Title, Description, Assignee, Priority, Due date, Status.

## FR-I4-037

**Statement:** Users shall be able to update task status.

**Related:** UC-I4-042..046, US-I4-019..021

> Collaboration features never directly mutate Ledger, Contribution, Payout, or Balance.
