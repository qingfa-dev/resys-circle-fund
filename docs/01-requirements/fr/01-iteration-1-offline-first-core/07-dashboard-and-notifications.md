# Dashboard & Notifications — Functional Requirements

**Iteration:** 1 — Offline-First Core ROSCA Management
**SRS:** `docs/01-requirements/srs.md` §3.1.7

## FR-I1-037 — Dashboard

**Statement:** The dashboard shall display: active circles, upcoming rounds, unpaid contributions, outstanding debt, recent activity, financial summary.

**Related:** UC-I1-038, US-I1-021, NFR-007 (Performance), NFR-014 (Usability)

## FR-I1-038 — Reminders

**Statement:** The system shall generate contribution reminders.

**Related:** UC-I1-039, US-I1-022

## FR-I1-039 — Reminder Status

**Statement:** The system shall track whether notifications were generated and/or delivered.

**Related:** UC-I1-040, NFR-032 (Notification Reliability); full delivery integration is Iteration 3 (FR-I3-001).
